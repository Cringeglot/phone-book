# Телефонный справочник (C++ / Qt)

Приложение для хранения и управления контактами. Разработка разбита на три этапа:
1. **Задача 0 (текущая):** проектирование структуры проекта и классов.
2. **Задача 1:** консольная программа на чистом C++ (STL) с сохранением контактов в файл.
3. **Задача 2:** добавление графического интерфейса на Qt и поддержки PostgreSQL с выбором способа хранения при запуске/сборке.

---
## 1. Архитектура проекта

Чтобы на первом этапе проект собирался без Qt, а на втором к нему можно было легко добавить окна и работу с БД, код разделён на две независимые части:

* **`core` (логика и данные):** описание контакта, проверка ввода через регулярные выражения, поиск, сортировка и сохранение данных. Написано только на стандартном C++ (STL).
* **`ui` (интерфейс):** консольное меню на первом этапе и графические окна на Qt на втором. Интерфейс работает только с классом `PhoneBook` и не зависит от того, куда именно сохраняются контакты.

Переключение между файлом и PostgreSQL в Задаче 2 будет задаваться прямо в `main.cpp` (через флаг сборки `#ifdef USE_POSTGRES` или аргумент командной строки).

## 3. Описание классов

### Папка `src/core`

* **`Contact.hpp` (`PhoneType`, `PhoneNumber`, `Date`, `Contact`)**
  * `PhoneType` — перечисление типов телефона: рабочий (`Work`), домашний (`Home`), служебный (`Service`).
  * `PhoneNumber` — структура с номером телефона и его типом.
  * `Date` — простая структура даты (`day`, `month`, `year`), чтобы не зависеть от Qt на первом этапе.
  * `Contact` — структура одного контакта: `id`, имя, фамилия, отчество, адрес, дата рождения, email и вектор телефонов (`std::vector<PhoneNumber>`).

* **`Validator`**
  * Набор статических методов для очистки и проверки полей
    * удаление лишних пробелов в начале, в конце и вокруг символа `@` в почте;
    * проверка ФИО (буквы, цифры, пробел и дефис; начинается с буквы; не начинается и не заканчивается на дефис);
    * проверка телефонов по форматам из ТЗ (`+7` или `8`, со скобками/дефисами или без);
    * проверка email (`<латиница и цифры>@<латиница и цифры>`);
    * проверка даты рождения (валидность дня и месяца с учётом високосных годов, дата меньше текущей).

* **`PhoneBook`**
  * Главный класс логики справочника. Хранит список контактов в памяти, проверяет данные через `Validator` перед добавлением/редактированием, выполняет поиск по нескольким полям, сортировку по выбранному полю и синхронизирует изменения с хранилищем.

* **`IStorage`**
  * Абстрактный класс с базовыми методами: `loadAll()`, `add()`, `update()`, `remove()`. Позволяет подменять файл на базу данных без изменения кода `PhoneBook` и интерфейса.

* **`FileStorage`** *(Задача 1 и 2)*
  * Наследник `IStorage`. Сохраняет и загружает список контактов из локального текстового файла.

* **`DbStorage`** *(Задача 2)*
  * Наследник `IStorage`. Работает с PostgreSQL через две таблицы: `contacts` (основные данные) и `phone_numbers` (телефоны с внешним ключом `contact_id`).

### Папка `src/ui`

* **`ConsoleUI`** *(Задача 1)*
  * Консольный интерфейс: вывод списка контактов, пошаговое добавление и редактирование с подсказками об ошибках ввода, удаление, поиск и сортировка.

* **`MainWindow`** *(Задача 2)*
  * Главное окно приложения на Qt. Содержит таблицу `QTableWidget` для вывода контактов (со встроенной сортировкой по столбцам), строку поиска по нескольким полям и кнопки добавления, редактирования и удаления.

* **`ContactDialog`** *(Задача 2)*
  * Диалоговое окно для создания и изменения контакта. Включает поля ввода с проверкой, виджет `QDateEdit` для выбора даты рождения и список для добавления/удаления произвольного количества телефонных номеров с выбором их типа.
